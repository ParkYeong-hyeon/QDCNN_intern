# Shared Notes

This directory contains cross-project concepts and background thoughts, mainly about general quantum computing topics that are relevant to multiple projects.

## Structure

- `literature/` - Paper summaries and bibliography on general quantum computing topics
- `insights/` - Casual insights and observations (more structured than scribble, less formal than concepts)
- `concepts/` - Shared concept-focused notes and summaries
- `ideas/` - Shared ideas and concepts across projects
- `experiment_design/` - Shared experimental design patterns and methodologies
