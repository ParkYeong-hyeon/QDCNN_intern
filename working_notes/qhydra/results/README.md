# Results Analysis

This directory contains analysis and summaries of experimental results for the Quantum Hydra project.

## Structure

- `analysis/` - Detailed analysis notes and interpretations
- `figures/` - Figures and visualizations
- `tables/` - Data tables and metrics
- `summaries/` - High-level summaries and key findings

## Usage

Results from experiments should be organized by:
- Experiment ID or date
- Model group (Group 1-4) or specific model
- Dataset (EEG frequency, synthetic benchmark)
- Analysis type (e.g., ablation, frequency-dependent analysis)
