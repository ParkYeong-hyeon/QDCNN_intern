# Results Analysis

This directory contains analysis and summaries of experimental results for the QDCNN project.

## Structure

- `analysis/` - Detailed analysis notes and interpretations
- `figures/` - Figures and visualizations
- `tables/` - Data tables and metrics
- `summaries/` - High-level summaries and key findings

## Usage

Results from experiments should be organized by:
- Experiment ID or date
- Analysis type (e.g., ablation, baseline comparison)
- Metric category (e.g., entanglement, performance)
