# Literature Review

## Purpose

This directory contains notes and summaries of research papers and articles relevant to the project.

## Format

Each paper should have its own markdown file following this naming convention:
- `YYYY-MM-DD_paperTitle.md` (e.g., `2026-01-03_paperA.md`)

## Template

```markdown
# Paper Title

**Authors**:  
**Year**:  
**Venue**:  
**Link**:  

## Summary

## Key Contributions

## Methodology

## Results

## Notes and Thoughts

## Citations

See [../../literature/bib/references.bib](../../literature/bib/references.bib) for BibTeX entries.
```

## Bibliography

All BibTeX entries should be maintained in [../../literature/bib/references.bib](../../literature/bib/references.bib), which is shared across all projects.
