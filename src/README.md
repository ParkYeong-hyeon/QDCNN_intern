# Source Code

This directory contains the main source code for the research project.

## Structure

- `config/` - Configuration files (YAML)
- `data/` - Dataset classes and preprocessing
- `models/` - Model implementations (baseline and custom)
- `training/` - Training and evaluation scripts
- `utils/` - Utility functions (logging, seed setting, etc.)

## Code Style

- Use type hints for all function signatures
- Include docstrings (Google style) explaining purpose and key concepts
- For quantum operations, explain the underlying quantum concepts
- Keep functions modular and focused
