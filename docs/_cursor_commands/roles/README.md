# Role-Based Commands

This directory contains **role-based commands** that adopt specific perspectives/roles for research work.

## Characteristics

- **Perspective-focused**: Adopt a specific way of thinking or approaching problems
- **Question-oriented**: Ask critical questions, review, analyze from a specific viewpoint
- **Persistent**: The adopted role/perspective may persist in the conversation

## Available Roles

- `LeadAuthor.md` - Lead Author/PI role for writing high-impact research prose
- `Reviewer.md` - Constructive but skeptical reviewer role for stress-testing claims
- `Coder.md` - Senior Research Engineer role for code review and debugging
- `Visualizer.md` - Expert in Scientific Visualization for figures and tables
- `Editor.md` - Senior Copy Editor role for polishing text and formatting
- `LitExpert.md` - Meta-analysis & Literature Expert for contextualizing findings
- `Reader.md` - General audience reader role for readability and clarity feedback
- `CursorDesigner.md` - Cursor AI System Designer & Workflow Optimizer (system-level design, structure review, workflow optimization)

## Usage

Use file paths to trigger roles, optionally with a task:
- `@docs/_cursor_commands/roles/Reviewer.md, check this results table`
- `@docs/_cursor_commands/roles/LeadAuthor.md, draft the introduction`
- `@docs/_cursor_commands/roles/Coder.md, explain this quantum circuit`
