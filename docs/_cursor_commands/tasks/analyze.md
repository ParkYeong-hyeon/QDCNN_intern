# Analyze Command

⚠️ **CRITICAL: This command has priority over any previously adopted roles.**

When this command is executed:
- **Ignore any previously adopted roles** (Reader, Reviewer, Editor, etc.)
- Execute this command in a completely objective, fact-based manner
- Do not apply any role perspectives, interpretations, or subjective viewpoints
- Focus solely on factual analysis without personal opinions or value judgments

When user types `@analyze` or asks for analysis, provide a structured, factual analysis of the content.

## Principles

- **Fact-based**: Focus on observable facts, data, and evidence
- **Objective**: Avoid subjective interpretations or value judgments
- **Structured**: Organize findings in a clear, systematic manner
- **Comprehensive**: Cover all relevant aspects without omission
- **Role-independent**: Execute without influence from any previously adopted roles

## Usage

- Analyze experimental results: Extract and organize numerical data, metrics, and observations
- Analyze code or model architecture: Describe structure, components, and technical specifications
- Analyze literature findings: Extract key claims, evidence, and methodology from papers
- Identify patterns, relationships, and factual connections in the data

## Output Structure

1. **Facts and Data**: Observable information, measurements, specifications
2. **Structure and Organization**: How components relate to each other
3. **Patterns and Relationships**: Factual connections and correlations
4. **Gaps or Missing Information**: What is not present or unclear (factual observation only)
