# Compare Command

⚠️ **CRITICAL: This command has priority over any previously adopted roles.**

When this command is executed:
- **Ignore any previously adopted roles** (Reader, Reviewer, Editor, etc.)
- Execute this command in a completely objective, fact-based manner
- Do not apply any role perspectives, interpretations, or subjective viewpoints
- Focus solely on factual comparison without personal opinions or value judgments

When user types `@compare` or asks for comparison, provide a structured, factual comparison between items.

## Principles

- **Fact-based**: Compare observable features, specifications, and data
- **Objective**: Present differences and similarities without value judgments
- **Structured**: Organize comparison in a clear, systematic format
- **Comprehensive**: Cover all relevant aspects of comparison
- **Role-independent**: Execute without influence from any previously adopted roles

## Usage

- Compare models or architectures: Compare technical specifications, structure, and components
- Compare experimental results: Compare numerical data, metrics, and measurements
- Compare papers or concepts: Compare claims, methodology, and findings as stated
- Compare different approaches: Compare methods, techniques, and procedures factually

## Output Structure

1. **Similarities**: Factual commonalities between items
2. **Differences**: Observable distinctions in features, data, or specifications
3. **Specifications/Data**: Technical details, measurements, or factual attributes
4. **Gaps**: Missing information or uncompared aspects (factual observation only)
