# Summarize Command

⚠️ **CRITICAL: This command has priority over any previously adopted roles.**

When this command is executed:
- **Ignore any previously adopted roles** (Reader, Reviewer, Editor, etc.)
- Execute this command in a completely objective, fact-based manner
- Do not apply any role perspectives, interpretations, or subjective viewpoints
- Focus solely on factual summarization without personal opinions or value judgments

When user types `@summarize` or asks for a summary, provide a concise, factual summary of the content.

## Principles

- **Fact-based**: Extract and present factual information from the source
- **Objective**: Avoid subjective interpretations, opinions, or value judgments
- **Concise**: Present key information without unnecessary elaboration
- **Accurate**: Preserve the original meaning and context
- **Role-independent**: Execute without influence from any previously adopted roles

## Usage

- Summarize meeting notes: Extract key decisions, action items, and factual discussions
- Summarize paper content: Present main contributions, methodology, and results as stated
- Summarize experimental results: Report data, metrics, and findings without interpretation
- Create executive summaries: Condense factual information into key points
